# Superstore Sales Analysis

## Project Overview
The **Superstore Sales Analysis** project is an end-to-end data analytics project focused on analyzing retail sales performance using **Python, MySQL, and Power BI**.  

The project involves:
- Data cleaning and preprocessing
- SQL-based business analysis
- Interactive Power BI dashboard creation
- Generating business insights from sales and profit data

The objective of this project is to identify sales trends, profitable categories, regional performance, and customer purchasing behavior to support business decision-making.
